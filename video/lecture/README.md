# Відеолекція 1 — «Теоретичні засади психології емоційного інтелекту»

Remotion-проєкт, 1920×1080, 30 fps. Озвучка — клон голосу викладача (OmniVoice, за його згодою),
субтитри — з таймінгів слів (Whisper), поточне слово підсвічується.

## Рушії озвучки (поле `engine` у `lecture/script.json`)

| `engine` | Голос | Аудіо | Примітки |
| --- | --- | --- | --- |
| `omnivoice` (поточний) | клон за зразком `voice-sample/ref-c.wav` + `refText` | `public/voiceover-omnivoice/` | Локально на GPU. Модель OmniVoice — **CC-BY-NC, лише некомерційно**. |
| `styletts2` | `"voice": "Поліна Еккерт"` | `public/voiceover-styletts2/` | Локальна українська StyleTTS2 (`models/styletts2-uk`). |
| `edge` | `"voice": "uk-UA-PolinaNeural"`, `"rate": "+0%"` | `public/voiceover/` | Microsoft Edge TTS, потрібен інтернет. |

Для `omnivoice` скрипт запускається з окремого середовища на диску D: (на C: не вистачає місця для PyTorch):
```
set HF_HOME=D:/ai-voice-env/hf
D:/ai-voice-env/venv/Scripts/python tools/voiceover.py
```
Кожен біт перевіряється Whisper; якщо збіг із текстом < 92 %, генерується знову з іншим зерном (до 5 спроб),
біти з позначкою ⚠ у виводі варто прослухати. Роки в тексті пишіть як `[1990|тисяча дев'ятсот дев'яностому]` —
цифри клон читає нечітко. Зразки голосу (вирізані з лекції викладача) — у `voice-sample/`, пробний абзац — `tools/clone_test.py`.

## Де що лежить

| Файл | Призначення |
| --- | --- |
| `lecture/script.json` | **Текст диктора** за сценами й бітами (абзацами). `[MSCEIT\|ем-ес-сі-ай-ті]` — показати / прочитати. |
| `lecture/plan.md` | Поминутний план і повний текст (генерується). |
| `tools/voiceover.py` | Синтез озвучки → `public/voiceover/`, таймлайн → `src/lecture/timeline.json`, субтитри → `out/final.srt`. |
| `src/lecture/scenes/*.tsx` | Візуальні сцени, згруповані за розділами: `Opening` (вступ, передумови), `Timeline` (історія, підходи), `ModelScenes` (модель, MSCEIT), `Day` (чотири здібності), `Practice` (психолог, розбір ситуації), `Closing` (завдання, висновки). Анімації прив'язані до слів через `cue(scene, "фраза")`. |
| `src/lecture/kit.tsx` | Візуальна мова v3: камера (`Camera`, `aim`), персонажі (`Person`), хмарка стану (`MoodCloud`), виноски, бульбашки, великі слова. |
| `src/lecture/DayWorld.tsx` | «Один день героїні» — спільний світ для чотирьох здібностей (ранок → полудень → вечір → ніч). |
| `src/lecture/Room.tsx` | Кабінет психолога — спільна сцена для розділу про роботу психолога й розбору ситуації. |
| `lecture/redesign-plan.md` | Таблиця переробки: таймкод → що було → що стало → яку думку пояснює кадр. |
| `_archive/lecture-v2/` | Попередня версія сцен (до переробки). |
| `src/lecture/Lecture.tsx` | Збирання: сцени поспіль, аудіо бітів, субтитри, смуга прогресу. |
| `tools/verify.py` | Перевірка готового відео: тривалість, гучність, синхронізація субтитрів, порожні кадри. |
| `tools/asr_check.py` | Розпізнавання озвучки Whisper і порівняння з текстом (контроль розбірливості). |

## Як змінити главу

1. Відредагуйте текст у `lecture/script.json` (або додайте сцену з новим `id`).
2. Згенеруйте озвучку й таймінги (змінені біти синтезуються заново, решта береться з кешу) — див. команду
   для обраного рушія вище.
3. Якщо змінилися ключові слова, на які прив'язана анімація, оновіть `cue(...)` у відповідній сцені —
   неіснуюча фраза одразу дасть помилку з назвою сцени.
4. Перегляд: `npm run dev` → композиція `Lecture1` або окрема глава в папці `Lecture1-chapters`.
5. Рендер і перевірка:
   ```
   npx remotion render Lecture1 out/final-teacher.mp4
   .venv-tts/Scripts/python tools/verify.py out/final-teacher.mp4
   ```

Середовище для скриптів: `python -m venv .venv-tts` → `.venv-tts/Scripts/pip install edge-tts pillow faster-whisper`.
Edge TTS потребує інтернету. Фонової музики немає — не було матеріалу з дозволеною ліцензією.

Шрифти (Manrope, Lora Italic; для трейлера — Unbounded, Exo 2, JetBrains Mono) лежать локально в `public/fonts`
і підключаються через `src/local-fonts.ts`, тож рендер не залежить від мережі. Інші накреслення: додайте їх у
`tools/fetch-fonts.mjs` і запустіть `node tools/fetch-fonts.mjs`.
