# Переробка візуальної режисури — Лекція 1

Озвучка, текст і таймінги не змінюються (голос викладача, 10:25). Змінюється лише картинка.

**Головна проблема v2:** майже кожна сцена = світле тло з кружечками + заголовок + картка/список, що з'являється по пунктах.
**Новий візуальний язик:** «світ» сцени з камерою (загальний план → крупний план → рух між пов'язаними елементами),
ілюстровані персонажі, схеми, що змінюють стан, великі ключові слова, м'яке світло замість декоративних кружечків.
Субтитри — у постійній нижній смузі, вся графіка стоїть вище неї.

**Наскрізна ідея для чотирьох здібностей:** один день однієї героїні. Приклади з озвучки складаються в одну історію:
ранок — одногрупниця каже «Усе нормально» (сприйняття) → полудень — хвилювання перед іспитом (використання) →
вечір — роздратування від утоми (розуміння) → ніч — різке повідомлення в чаті (управління).
Над героїнею весь час видно її «емоційний стан» (м'яка хмарка), який змінюється від кроку до кроку,
а камера переїжджає вздовж одного панорамного «дня».
